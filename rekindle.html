Rekindle

Play Clickteam Fusion games on a modern runtime: faster to start, lighter on memory, and on more platforms.

Download Compatibility GitHub

Latest release · Free and open source · Windows, Linux, Steam Deck

About

Rekindle is a clean-room runtime for games made with Clickteam Fusion 2.5 and Multimedia Fusion 1.5, written from scratch in Rust. It reads a game's own .exe (or its data file) and runs it directly, the way ScummVM does for old adventure games, so games that only ever shipped for Windows can run natively on Linux and the Steam Deck, with no Wine or Proton needed.

It comes with a launcher that keeps your library, makes desktop and Steam shortcuts, tracks play time and updates itself. Rekindle includes no game files: it plays copies of games you already have.

See the compatibility list for the games tested so far.

Features

Launcher

Add a game or a whole folder, play with one click, see time played, and make desktop shortcuts with each game's own icon.

Steam integration

Finds Clickteam games you installed through Steam and adds games to Steam as shortcuts, with their store artwork, or artwork made from the game.

Controller support

Play keyboard-and-mouse games with a gamepad: buttons map to keys, and a stick moves a virtual cursor. Remappable per game.

Better display

Proper fullscreen, sharp / smooth / enhanced upscaling, and fit, integer or stretch scaling, all set per game.

Mods

Replace any image or sound by dropping files in a game's mods folder. The game files are never changed.

Lightweight

Game data is read straight from disk and music is streamed, so games start fast and use less memory.

Download

Each button downloads the newest release for that platform. The launcher updates itself after that.

Windows

Windows 10 and 11, 64-bit. A single program, nothing to install.

Download for Windows

Steam Deck

In Desktop Mode: download, right-click → Properties → Permissions → "Is executable", then open it. Rekindle adds itself to Steam for Gaming Mode.

Download for Steam Deck

Linux

An AppImage that runs on most 64-bit distributions. Make it executable (chmod +x) and run it. Prefer a plain binary?
