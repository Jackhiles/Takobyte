# TakoByte

The website for TakoByte — games, tools, and other projects.

## Overview

TakoByte is a personal projects site featuring a dark, single-stylesheet design with no external UI framework
dependencies. It showcases games, a homelab overview, public accounts, and links to where TakoByte's projects
can be found.

## Pages

- `index.html` — Home, About, Games, and Homelab sections
- `tako.html` — Public gaming and anime/visual novel accounts
- `stickyships.html` — Sticky Ships game page with screenshots
- `ucnmaker.html` — UCN Maker game page with features and screenshots
- `privacy.html` — Privacy policy

## Features

- Sticky navigation bar with mobile hamburger menu
- Responsive layout for desktop and mobile
- Embedded Discord widget
- Screenshot gallery for Sticky Ships
- Homelab section listing self-hosted services (no direct links, for safety)
